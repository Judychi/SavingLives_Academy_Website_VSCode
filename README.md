# SavingLives Academy Website

A responsive static website starter built with HTML, CSS, and vanilla JavaScript using the SavingLives Academy flyer as the visual reference.

## Brand palette

- Navy: `#062B53`
- Yellow: `#FFC928`
- Teal: `#0BB5AD`
- White: `#FFFFFF`

These are web approximations selected to match the flyer visually.

## Files

- `index.html` — website content and page sections
- `styles.css` — layout, responsive styling, brand colours, typography
- `script.js` — mobile navigation and demo form behaviour
- `assets/savinglives-academy-flyer-reference.jpeg` — supplied flyer for reference, if included

## Preview in VS Code

1. Extract the ZIP file.
2. Open the extracted `savinglives-academy-website` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Edit `index.html` for wording and page content; edit `styles.css` for design.

The page uses Google Fonts and a remote Unsplash image. Internet access is needed for those external assets. Replace the image with an approved academy photo before launch if preferred.

## Important before publishing

1. The registration form is a front-end demo only. It does not send or store submissions.
2. In GoHighLevel, the recommended approach is to create a native GHL form and embed it or link the Register button to a GHL form page. Configure the relevant workflow/notifications and test them.
3. Confirm the cohort date, fee, class schedule, course details, payment methods, contact information, and any claims before publishing.
4. Add the academy's approved privacy notice and consent language.
5. Connect a domain and configure DNS/SSL with the instructions shown in the actual GHL account or hosting provider.

## Using this with GoHighLevel

This is a standalone HTML/CSS/JS version for VS Code. It is not automatically imported into the GHL visual Website Builder. To use the same design in GHL, recreate the sections with the builder, or use a supported custom-code/HTML element where appropriate. Do not paste the entire site into a single section unless your GHL editor supports that setup and you have tested responsive behaviour.
